# Вопросы

1. В Dart тип переменной проверяется на этапе компиляции, а не во время выполнения.
Компилятор заранее видит несоответствия типов и не даёт собрать программу.

2. String — переменная, которая гарантированно не может быть null.
String? — nullable-тип, допускает значение null.

3. final защищает от ошибок, когда код пишут несколько человек или когда
переменная используется спустя месяцы.

4. Позиционные параметры передаются по порядку: f('Артём', 20).
Именованные — по имени: f(name: 'Артём', age: 20), порядок не важен.
